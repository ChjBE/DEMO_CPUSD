# DEMO_CPUSD
# CPU Scheduling Simulator

## Giới thiệu
Hệ thống mô phỏng trực quan các thuật toán lập lịch CPU trong môn Hệ điều hành.

## Các chức năng
- Mô phỏng quá trình thực thi các tiến trình.
- Trực quan hóa hàng đợi Ready và biểu đồ Gantt.
- So sánh hiệu suất các thuật toán lập lịch CPU.
- Phân tích các kịch bản tải CPU và đề xuất thuật toán phù hợp.
